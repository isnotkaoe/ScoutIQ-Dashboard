# ScoutIQ Dashboard

A modern football analytics dashboard built with HTML, CSS and Vanilla JavaScript.

## Features

- Modern dashboard layout
- Animated sidebar
- Responsive cards
- SVG line chart
- Donut chart
- Animated counters
- Performance panels
- Glassmorphism UI
- Hover animations
- Live clock

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- SVG

## Purpose

This project was created as a front-end practice to improve UI development skills and dashboard design without using frameworks.
